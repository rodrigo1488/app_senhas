# CompuFlow — painel web

Painel administrativo Next.js do CompuFlow (filas, operadores, TV, analytics).

## Dev

```bash
npm install
API_INTERNAL_URL=http://127.0.0.1:5000 npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

Login padrão (primeira subida da API): `admin@compuflow.local`.
